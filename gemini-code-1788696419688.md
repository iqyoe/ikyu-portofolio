# 🚀 Data Engineering Portfolio - Development Progress

## 📌 Project Overview
Building a high-performance, dark-themed data engineering portfolio using **Next.js (App Router)**, **Tailwind CSS v4**, and **MDX**, inspired by the sleek "Gerold" design aesthetic.

---

## 🛠️ Tech Stack & Architecture
* **Framework**: Next.js (App Router)
* **Styling**: Tailwind CSS v4 (`@tailwindcss/typography`)
* **Content Engine**: MDX (`next-mdx-remote`)
* **Data Visualizations**: Mermaid.js (`mermaid`)
* **Asset Optimization**: Next.js `Image` component

---

## ✅ Completed Steps & Accomplishments

### 1. Environment & Data Layer Setup
* Configured local environment and server setup.
* Established the content data layer in `src/lib/projects.ts` to parse `content/projects.json` and `.mdx` files.
* Configured TypeScript interfaces (`ProjectMetadata` and `ProjectCaseStudy`) to handle project attributes, including tags, categories, and image paths.

### 2. Homepage & Interactive Filtering (`/`)
* Built `src/components/ProjectGrid.tsx` with dynamic tag-filtering capabilities ("All", "Python", "Pandas", etc.).
* Implemented thumbnail cards with hover-scaling image containers (`group-hover:scale-105`) and clean fallback padding.
* Resolved asset URL paths (using forward slashes `/image/projects/...`) to ensure smooth rendering with Next.js `<Image />`.

### 3. Dynamic MDX Case Study Routing (`/projects/[slug]`)
* Built dynamic route `src/app/projects/[slug]/page.tsx` using `generateStaticParams` for SSG (Static Site Generation).
* Connected `next-mdx-remote` for client/server MDX parsing.
* Built a custom React client component `src/components/Mermaid.tsx` to render interactive system flowcharts directly from MDX code blocks.
